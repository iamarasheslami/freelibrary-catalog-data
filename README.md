# FreeLibrary Catalog Data

Generated catalog export data for the [FreeLibrary](https://github.com/iamarasheslami/freelibrary)
Android app: a manifest of every book's ID and last-modified date, plus individual per-book
metadata files, sourced from Project Gutenberg's RDF catalog.

This data is generated by FreeLibrary's `catalog-tool` and updated automatically. It is not
meant to be browsed manually — it exists to be fetched by the app's sync mechanism.

## Structure

- `manifest.json` — every book's `externalId` and `lastModified` date. Always kept fully
  current; small enough to be fetched in full on every app sync.
- `books/<externalId>.json` — one file per book, containing its title, creators, subjects,
  bookshelves, and available download formats.
